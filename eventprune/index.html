01 / Motivation

Preserve the geometry needed for reasoning

Motion changes what is informative

Embodied spatial reasoning requires tracking continuous motion and precise geometry during rapid ego-motion. RGB-only pruning often selects tokens from discrete snapshots; motion-rich moments and object boundaries can disappear under compression.

Attention is useful, but can be biased

In our evaluated Video-LLM, attention consistently favors image borders. High attention alone can therefore retain peripheral tokens while discarding central structure. Event cameras provide an external cue: asynchronous brightness changes expose motion and geometric boundaries.

ECP combines this motion prior with semantic attention, using events to guide which RGB tokens remain.

02 / Method

A training-free, three-stage cascade

ECP reduces temporal and spatial redundancy in sequence. Event activity determines pruning scores and masks; it is not encoded as additional event embeddings or injected into hidden representations. Retained RGB tokens continue through the backbone, and text and special tokens remain available.

ETS Event-guided temporal sampling

Partition events into fixed temporal windows and apply a spatiotemporal density filter. Select windows with high event activity Sn and large activity changes, then refine anchors for temporal coverage and map them to RGB keyframes.

ΔSn = |Sn − Sn−1|

EMSF Motion-saliency filtering

Accumulate temporally aligned events over each token’s spatial support. Min–max normalize the counts within each frame, then keep the highest-saliency candidates before subsequent attention.

K = ⌊ρN⌋   ·   keep top-K saliency

EARF Event–attention ranking fusion

Read text-conditioned visual attention from the preceding attention map. Rank-normalize attention and event saliency within each keyframe, fuse the ranks, and retain top-K RGB tokens at selected layers.

S = (1 − γl) R(A) + γl R(M)

Why fuse ranks?

Attention scores and event density both have long-tailed distributions. A direct weighted sum of raw scores can be dominated by outliers or by the modality with the larger numerical scale. Per-frame rank projection maps both signals to a shared range while preserving their ordering. Layers with more consistent peripheral bias receive stronger event calibration; deeper layers retain more semantic flexibility.

How can calibration improve the downstream key–value context?

The appendix interprets the mechanism through the active keys and values retained for later attention. An event-unsupported peripheral token may have a high attention rank and a low event rank. When its attention rank is near 1 and its event rank near 0, its fused score is approximately 1 − γl; a token supported by both cues can score near 1.

After per-keyframe top-K selection, the retained visual tokens are merged across frames. Removed visual keys and values are no longer forwarded to subsequent layers. This is an analytical interpretation of how calibrated selection changes the active context; it does not imply that all peripheral tokens should be removed. Peripheral tokens with strong event support can still be retained.

How are simulated events produced?

vid2e processes each original RGB video at its native frame rate and synthesizes events between adjacent original frames. The reported settings are positive and negative contrast thresholds cp = cn = 0.2 and refractory period tref = 0. ETS scores the full simulated stream; EMSF and EARF use event windows aligned with retained RGB keyframes. ESR-Real uses hardware events and requires no event simulation.

Causal ETS: prefix-only frame selection

The streaming selector scores only observed windows, normalizes activity with historical EMA statistics, and maintains at most 64 RGB frames. On overflow, it removes the lower-priority member of the temporally closest pair while protecting the first and most recent prefix frames. EMSF and EARF remain unchanged.

07 / ESR-Real dataset

Native RGB–event data for embodied spatial reasoning

ESR-Real contains 700+ QA pairs across six tasks, organized into Perception, Cognition, and Reasoning & Planning. Recordings span offices, laboratories, corridors and common areas, with natural handheld walking, turning and approaching objects. Sequence durations range from 50.1 to 153.3 seconds.

Perception

Goal Perception
At the final viewpoint, is the specified navigation destination visible?
Trajectory Scene
Which objects are observed while the viewpoint follows a specified trajectory?

Cognition

Relative Distance
Which object is closest to a target, using the closest point of each object?
Motion Assumption
How does distance to a target change during a specified action?

Reasoning & Planning

Direction Reasoning
Given a robot’s position and facing direction, is a queried object left, right or behind?
Route Planning
What actions reach a destination from a specified position and orientation?

Original dataset examples

Capture and alignment

Event sensor

Prophesee EVK4 HD / Sony IMX636ES
1280 × 720 resolution; microsecond temporal resolution; >120 dB dynamic range.

RGB sensor

Hikvision MV-CS050-10UC / Sony IMX264
2448 × 2048 global-shutter imaging; the camera supports up to 60 fps.

The cameras are rigidly mounted on a 3D-printed handheld bracket, with an approximately 5 cm baseline. Calibration estimates camera intrinsics and the inter-camera transformation using checkerboards; event-based intensity reconstruction supports stereo corner matching. RGB frames are warped onto the native 1280 × 720 event image plane.

Sensor specifications and calibration protocol

The event sensor has a 4.86 μm pixel pitch and low-light sensitivity down to 0.08 lux; the RGB sensor has a 3.45 μm pixel pitch and a USB 3.0 interface. The RGB camera’s 60 fps value is its supported maximum frame rate.

Intrinsic calibration uses 20–30 RGB images of a 4 × 7 checkerboard with 80 mm squares at different orientations and distances. A blinking checkerboard and Metavision calibration pipeline support the event camera. E2VID-reconstructed event frames provide corners for stereo calibration, which estimates the rotation and translation between the sensors before RGB-to-event warping.

From recordings to reviewed QA

  1. Build spatial metadata. Identify salient objects with unique visual names, describe spatial relations and scene layout, and mark proximity pairs.
  2. Populate task templates. Vary robot position and orientation, derive answers from the metadata, and generate logically distinct distractors. Non-proximity constraints make selected tasks require reasoning over extended trajectories.
  3. Refine by human review. Correct ambiguous targets, hallucinated objects, geometric errors and poorly differentiated answer choices. The refinement required over 200 person-hours.

Scope and limitations

ECP assumes synchronized RGB–event inputs and targets platforms that pair event sensing with RGB. Gains depend on task, budget and backbone; Video-MME includes categories and budgets where FastV performs better. Model-side efficiency with prepared events does not include offline synthesis. Backbone transfer adapts token mapping and pruning configuration rather than using identical layer indices everywhere.
